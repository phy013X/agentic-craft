# Definition of Done —— 完成前自检

## 按变更面选最小证据

| 变更类型 | 必须提供的证据 |
|---|---|
| 行为/逻辑 | 覆盖该路径的行为测试（含失败路径），且新测试亲眼见它先红后绿 |
| 公开接口/命令/配置/导出 | 接口文档同步 + 消费方仍编译/通过 |
| 性能敏感改动 | 前后测量数值 + 测量条件（不许只说「更快了」） |
| 重构（行为应不变） | 证明行为不变的证据（快照/期望输出不变） |
| 仅文档 | 文档一致性检查 + 死链检查 |
| UI 改动 | 至少一处实际渲染/截图证据 |
| AI 项目：prompt/工具 schema/模型可见输出 | 对应录制回放/快照更新（见 `docs/ai/record-replay.md`） |

## 纪律

- 通过的检查**不重复全量跑**；全量回归与平台矩阵交给 CI。
- 报告只写**实际跑过的命令**与结果；没跑的绝不声称跑过。
- 发布/合并前执行一次受影响范围的相关检查（如 typecheck、相关测试）。
- 不满足上表对应行，就还不算「完成」。

## 变更说明收尾

按 `.github/PULL_REQUEST_TEMPLATE.md` 填写：动机 / 接口改动（无则写 None）/ 行为改动（**只写被测试覆盖的**）/ 测试（附证据）/ AI 参与度（见 `docs/ai-usage.md`）。
