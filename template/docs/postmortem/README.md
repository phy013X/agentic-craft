# 事故复盘（Post-mortem）

复盘追**流程**不追人。重点不是那一行修复，而是「为什么每一道安全网都放它过去了，以及加了什么让同类 bug 下次必炸」。

## 何时写

同时满足：
- **机制非显然**：一个细心工程师也得费劲重新推导才能搞懂；
- **体系性逃逸**：它漏出是因为测试/工具/约定的缺口，而非一次性笔误；
- **重查代价高**：已经花了真实调试时间，将来还会再花。

## 与 ADR 的区别

ADR 记录**主动的**设计决策与被否决方案；复盘记录**被动的**失败：怎么坏的、机制、为何每道网都没拦住、补了哪些护栏。

## 结构

见 `0000-template.md`：30 秒可读完的执行摘要 + 时间线 + 根因 + **新增的护栏** + 教训。每篇必须链接它催生的具体护栏（新测试、新门禁、新规则）。
