# AI 参与度分级标准

把「AI 写了多少、人在哪把关」变成可见的结构化信息。AI 参与度越高的改动，需要越严的人工评审——`auto` 级实现默认要求人**逐行读懂 diff** 才能合并。

## 五个级别

| 级别 | 含义 | AI 大致占比 |
|---|---|---|
| `hint` | 人独立完成，AI 仅提供零星提示 | 0–10% |
| `assist` | 人主导，AI 补全局部 | 10–35% |
| `pair` | 人引导方向，AI 与人来回结对 | 35–55% |
| `copilot` | AI 生成主体，人持续把关、纠偏 | 55–85% |
| `auto` | 模型自主完成，人事后评审 | 90–100% |

## 五个阶段

对一次改动分别在 **拆解 breakdown / 设计 design / 测试 testing / 实现 implementation / 评审 review** 各标一级。占比不必精确，取最接近的一级即可。

## 必填项

- 「关键决策由谁拍板」：哪怕实现是 `auto`，也要写清架构/取舍层面的决定是人做的还是 AI 做的。
- 铁律：无论级别高低，**人必须读懂 diff 才合并**；`design` 阶段为 `auto` 的改动，要额外确认人理解并认可其方案，而非仅接受能跑的代码。
