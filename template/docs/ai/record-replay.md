# AI / LLM 项目的最小「录制-回放」回归实践

（仅做 LLM/AI 应用的项目需要。）目标：把**非确定、要花钱的模型调用**，变成**确定性、零 token、可在 CI 无密钥运行的回归测试**。

## 核心思想

> 真实业务代码、真实工具、真实副作用**全部跑真**，唯一被替换掉的是「模型」这一个非确定边界。

## 最小步骤

1. **录制（一次性，花 token）**：用真 API 跑一遍场景，把「请求 + 模型原始响应流」原样存成 fixtures（如 JSONL）入库。
2. **回放（默认，免费）**：在适配器层挂一个「回放替身」，按录制顺序吐出模型响应，驱动**真实的**后续逻辑与工具副作用。CI 无需 API key。
3. **规范化是纯函数**：比对前只用纯函数抹掉易变值（时间戳、临时路径、自增 ID → 稳定占位符）。**绝不抹掉 payload、事件顺序、或「意外多出的字段」**——这些正是回归要暴露的东西。
4. **副作用独立断言**：会写文件/改状态的场景，把「最终产生的文件树/状态」作为独立期望结果断言，且**录制命令永不覆盖它**。这是防止「模型说了什么不算数，外部世界的字节才算数」的预言机。
5. **纪律：修 fixtures，不修 normalizer**：测试红了去修真实夹具或被测代码，不许在比对器里放水（抹掉不稳定项让测试假绿）。

## 配套

- 真 API 的 e2e 单独一层：**无 key 自动 skip，有 key 才跑**——它证明「产品对真模型真的能用」，与回放层（证明「逻辑确定正确」）互补。
- 分层：快单测（本地随时）/ 回放集成（PR 必过）/ 真 API e2e（有 key 才跑）。
