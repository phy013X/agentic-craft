# 架构决策记录（ADR）

记录「为什么」和「放弃了什么」，防止决策只存在于某次聊天、防止后人重复争论已被否决的方案。

## 规则

- 只记录**有持久取舍**的决策（架构、数据格式、对外兼容、不可逆选择）；机械性改动免写。
- 一篇一个决策，文件名 `NNNN-short-slug.md`，编号递增。
- 必填五段见 `0000-template.md`。**Alternatives considered（被否决的方案及理由）不可省略**。
- 决策被推翻时**新开一篇并互链**，旧文标 `Status: superseded by NNNN`，不回改旧结论。
- 事实性内容（路径、默认值）随代码变化在同 PR 更新；已落地决策用现在时描述。
